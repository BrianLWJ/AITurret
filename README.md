# AITurret
My Internship training Exercise that contains
-  State Machine (Idle, Shooting, Overheat, Reloading)
-  Object Pooler
-  Simple Player Movement

Starting Exercise

Create a turret that will track and shoot player
The turret will be static and track player position, but only shoot if the player within its shooting
range
The turret has 4 states - idle, shooting, overheat, reloading
Use state machine to control the changing of states
Apply object pooling for the bullet used by the turret
 Create a player that can move freely with WASD control
Timeline:
Start Date: Upon receiving of the task.
Deadline: 1 week from the start date.
